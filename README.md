# Chifacom
Mobile healthcare management application connecting patients and healthcare professionals.

## Tech Stack : 
 - android studio 4.1
 - sdk version : 29
 - gradle version: 4.1.0
 Things includes in first push:
 - splash screen 
 - first run activity (only run at first installation)
 - login form 
 - login web service ( using php )
 - register fragments ( 4 steps -> 4 fragments )
 - register web service 
 - database using mysql


## Features

- Splash Screen
- First Run Experience
- User Authentication
- Login System
- Registration Wizard (4-Step Process)
- User Profiles
- Messaging System
- Backend API Integration
- MySQL Database
